    02 // BUILT FOR DAILY FLOW

    Dirancang Presisi untuk Pengguna Windows

    01 / AUDIO & SYNCED LYRICS

    Integrasi Musik Windows GSMTC & Lirik Real-Time

    Terhubung langsung dengan Spotify, YouTube di Browser, maupun Apple Music. Dilengkapi fitur ekstraksi warna sampul album otomatis untuk menghasilkan gradasi latar yang hidup serta tampilan Compact Idle Lyrics (1 baris lirik + judul lagu) saat mouse tidak menyentuh Notch.

    02 / SMART PROXIMITY

    Anti-Tabrakan dengan Tab Browser

    Membuka banyak tab di Chrome atau Edge? MangNotch memindai posisi tab dan tombol + secara real-time, lalu otomatis menyusut menjadi garis tipis 6px agar tab di bawahnya bebas diklik.

    03 / NATIVE OLE FILE SHELF

    Drag-In & Drag-Out Tanpa Hambatan

    Tarik file dari Windows Explorer ke dalam Notch untuk disimpan sementara, lalu tarik keluar langsung ke ruang obrolan WhatsApp, Discord, atau aplikasi lainnya tanpa peringatan keamanan yang mengganggu.

    04 / FOCUS & HYDRATION

    Pomodoro Timer & Water Wave Tank

    Dilengkapi timer fokus beranimasi, indikator tangki air bergelombang, daftar tugas instan, serta synthesizer suara chime lembut berbasis Web Audio API yang dapat diatur On/Off sesuai keinginan.

    05 / TRUE FULLSCREEN HIDE

    Hilang 100% Saat Bermain Game

    Mendeteksi secara pintar perbedaan antara jendela Maximized biasa dan layar penuh murni (Game / Video F11). Saat bermain game, jendela Notch disembunyikan sepenuhnya (0 piksel).

    03 // HEADLESS TRAY ARCHITECTURE

    Berjalan Senyap di Background, Dikendalikan Lewat System Tray.

    Saat komputer menyala, MangNotch langsung mengaktifkan Notch di layar utama tanpa memunculkan jendela pengaturan yang mengganggu. Kapan pun kamu ingin mengganti maskot (MangCat, PitVisor, atau Kitsune), memilih monitor eksternal, atau mengelola To-Do List, cukup klik ikon MangNotch di System Tray.

    • 3 Karakter Maskot Eksklusif: MangCat (Cyber-Neko), PitVisor HUD, dan Kitsune Orbs.
    • Multi-Monitor Ready: Otomatis mengikuti Primary Display atau kunci ke monitor pilihanmu.
    • Penyimpanan Lokal Bersih: Seluruh konfigurasi tersimpan rapi di %AppData%\MangNotch.
